## ジャーニー寸法 {#MBE_table_wk4_bnj_w2b}

次の表に、ジャーニーレポートで使用されるディメンションのリスト、定義および式を示します。

| ディメンション | 定義 |
|--- |--- |
| **アクション** | ジャーニーで使用されるすべてのアクション（**アクション名 – アクションラベル**）のリスト（例：プッシュ – チェックアウト確認、電子メール – リワードの忠実度）。 |
| **データソース** | ジャーニーのデータを強化するために使用されるデータソースのリスト（**データソース名**）（例：Adobe Experience Platform、Reservation system）。 |
| **[!UICONTROL イベント]** | ジャーニーで使用されるすべてのイベント（**イベント名 – イベントラベル**）のリスト（例：Geometrixx イベント - Geometrixx チェックアウト）。 |
| **フィールドグループ** | ジャーニーのデータを強化するために使用されるフィールドグループのリスト（**フィールドグループ名**）（例：プロファイルフィールドグループ、Geometrixx予約システム）。 |
| **ジャーニー** | テストモードとライブのすべてのジャーニー（**ジャーニー名**）のリスト（カート放棄、ホテル予約通知など）。 |
| **ジャーニー版** | ジャーニーのすべての公開済みバージョンのリスト（**ジャーニー名+ バージョン番号**）例：買い物かごの放棄v1、ホテル予約通知v2。 |
| **オーケストレーション** | ジャーニーで定義され、使用されているすべてのオーケストレーションアクティビティ （**条件、終了、待機**）のリスト。 |

## 配信ディメンション {#delivery-dimensions}

次の表に、ジャーニーレポートで使用される配信ディメンションのリスト、定義および式を示します。

| ディメンション | 定義 |
|--- |--- |
| **ブラウザー** | メッセージが開かれたかクリックされたブラウザー。 |
| **配信名** | 配信のラベルとID。 |
| **デバイス** | 電子メール/SMS/プッシュ通知の開封元/閲覧元/クリック元のデバイス。 |
| **メッセージの種類** | 電子メール、SMS、プッシュ通知、アプリ内など、配信に使用されるチャネル。 |
| **モバイルアプリ名** | モバイルアプリケーションの名前 |
| **プラットフォーム** | メッセージの開封元/閲覧元/クリック元のデバイスのプラットフォーム。 |
| **[!UICONTROL プッシュプラットフォーム]** | IOSやAndroidなど、プッシュ通知を開いたデバイスのプラットフォーム。 |
| **受信者ドメイン** | メールを開くために使用されるドメイン。 |
| **トラッキング URL** | メッセージからユーザーがクリックしたURL。 |
| **トラッキング URL カテゴリ** | トラッキング URLに割り当てられたカテゴリ。 |
| **トラッキング URL ラベル** | ミラーページなどのURLに指定されたラベルは、お問い合わせいただくか、開いてください。 |
| **バリアント** | A/B テストの場合のメールのバリエーション。 |

## ジャーニー指標 {#MBE_p_p22_c4j_w2b}

次の表に、ジャーニーレポートで使用される指標のリスト、定義および式を示します。

| 指標 | 定義 |
|--- |---|
| **完了** | ジャーニーを通常どおりに終了した個人の合計数。 |
| **完了率** | ジャーニーにエントリした個人の合計数に対して、通常ジャーニーを終了した個人の合計数。 |
| **現在** | 現在ジャーニーに参加している個人の合計数（入力した人数から離脱した人数、エラー、タイムアウトした人数を差し引いた数）。 |
| **現在のレート** | ジャーニーにエントリした個人の数に対する、現在ジャーニーにエントリしている個人の合計数。 |
| **エントリ済み** | ジャーニーの個々のエントリを開始するために発生したイベントの合計数。 |
| **エラー** | ジャーニー中に発生したが、ジャーニーが成功しなかったエラーの合計数。 |
| アクション **の** エラー | アクションに対して発生したエラーの合計数。 |
| **エンリッチメントのエラー** | データソース/フィールドグループの呼び出し時にデータエンリッチメントに発生したエラーの合計数。 |
| **イベントのエラー** | イベントで発生したエラーの合計数。 |
| **エラー率** | ジャーニー中に発生したエラーの合計数と、ジャーニー内で発生したエラーの合計数を比較します。 |
| **実行されたアクション** | ジャーニーに対して実行されたアクションの合計数。 |
| **エンリッチメントを実行** | 特定のフィールドグループを取得するためにデータソースを呼び出して実行されたエンリッチメントの合計数。 |
| **実行されたイベント** | ジャーニーに対して実行されたアクションの合計数。 |
| **オーケストレーションを実行** | ジャーニーに対して実行されたオーケストレーションオブジェクト（終了、待機、条件）の合計数。 |
| **失敗** | 正常に実行されなかったジャーニーの合計数。 |
| **失敗率** | 実行されなかったジャーニーの合計数と、実行されたジャーニーの数を比較します。 |

## 配信指標 {#delivery-metrics}

以下の表は、ジャーニーで使用される指標のリストです
レポート、定義、計算式。

| 指標 | 定義 |
|--- |--- |
| **ブロックリスト** | 電子メールをスパムまたは迷惑メールとして宣言した受信者の数。 |
| **ブロックリスト率** | 送信されたメッセージと比較したメッセージの合計数です。 |
| **バウンス + エラー** | 送信されたメッセージの合計数に対して、配信および自動返信処理の間に発生したエラーの累計。 |
| **バウンス + エラー率** | 送信されたメッセージとバウンスしたメッセージの合計数。 |
| **クリック** | 配信でコンテンツがクリックされた回数。 |
| **クリック率** | 配信されたメッセージの数に対する、配信の合計クリック数。 |
| **配信済み** | 送信されたメッセージの総数に対して、正常に送信されたメッセージの数。 |
| **配信率** | 正常に配信されたメッセージと送信されたメッセージの合計数。 |
| **エラー** | ジャーニー中に発生したが、ジャーニーが成功しなかったエラーの合計数。 |
| **ハードバウンス** | 間違った電子メールアドレスなど、永続的なエラーの合計数です。 |
| **ハードバウンス率** | 永続的なエラーが原因で失敗した配信と、送信されたメッセージの合計数。 |
| **ミラーページ** | ミラーページリンクをクリックした受信者の数。 |
| **ミラーページ率** | ミラーページリンクのクリック数の合計数と、配信されたメッセージの合計数を比較します。 |
| **オープン** | 配信でメッセージが開かれた回数。 |
| **開封率** | 配信されたメッセージの数に対する、開封されたメッセージの合計数。 |
| **強制隔離** | バウンスし、アドレスの強制隔離に至ったメッセージの数。 |
| **強制隔離レート** | 送信されたメッセージと比較した強制隔離の合計数。 |
| **却下** | SMTP サーバーによってスパムとして分類されたメッセージの数。 |
| **却下された率** | 送信されたメッセージと比較して、拒否としてマークされたメッセージの合計数。 |
| **処理/送信** | 配信の合計送信数。 |
| **ソフトバウンス** | 完全な受信トレイなど、一時的なエラーの合計数。 |
| **ソフトバウンス率** | 一時的な理由で失敗した配信と、送信されたメッセージの合計数です。 |
| **ユニーククリック** | 配信内のコンテンツをクリックした受信者の数。 |
| **ユニーク開封数** | 配信を開いた受信者の数。 |
| **購読解除済み** | 購読解除リンクのクリック数。 |
| **登録解除率** | 配信されたメッセージと比較した、受信者による登録解除の合計数。 |
